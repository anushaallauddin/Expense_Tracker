# Expense Tracker

A Python-based Expense Tracker application designed to manage, organize, and analyze personal financial transactions.

## Features

- Add income and expense transactions
- View all transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Search transactions by category
- Filter transactions by income or expense type
- Generate category-wise expense summaries
- Generate monthly financial summaries
- Delete transactions
- Store transaction data in CSV format

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- CSV File Handling
- Data Processing
- Command Line Interface (CLI)
